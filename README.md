# 매장 운영 관리 (한식 · 영업 11:00–21:00)

Next.js 16 (App Router) + Supabase (프로젝트 `store-ops`, 서울 리전).

## 기능과 권한

| | 사장 | 관리자 | 직원 |
|---|---|---|---|
| 출퇴근 (매장 NFC 태그로만), 내 기록 보기 | O | O | O |
| 내 비밀번호 변경, 비밀번호 찾기(메일) | O | O | O |
| 전 직원 출퇴근 기록 보기 (날짜별) | O | O | X |
| 출퇴근 시간 수정 / 누락 기록 추가 | O (전원) | O (**본인 제외**) | X |
| 직원 계정 생성, 권한·고용형태 변경, 사용 중지 | O | X | X |
| 직원 비밀번호 초기화 | O | X | X |
| NFC 코드 관리 | O | X | X |

- 계정은 사장만 만들 수 있고, 아무나 가입할 수 없습니다(공용 계정 금지).
- 출퇴근 시간은 서버 시각으로 기록됩니다. 출근 후 1분 안에는 퇴근이 되지 않습니다.
- **자동 퇴근 처리:** 21:30(한국 시간)까지 퇴근을 찍지 않으면 21:00 퇴근으로 기록하고 "자동 퇴근 처리"로 표시합니다. Supabase pg_cron이 10분마다 실행하고, 태그를 찍을 때도 먼저 확인합니다. 자동 퇴근된 날에는 다시 출근이 찍히지 않습니다. 실제 퇴근 시간은 사장/관리자가 고칩니다(고치면 "자동 퇴근 처리" 대신 "수정됨"으로 표시).
- 관리자/사장이 시간을 고치면 `attendance_logs`에 이전 값과 바뀐 값이 남습니다. 직원 화면에는 "관리자 수정됨"으로 표시됩니다.

## 오픈·마감 체크리스트 (`/checklist`, 기록 확인 `/admin/checklists`)

- 항목 종류: ✔ 체크 / 🔢 숫자 입력(냉장고 온도 등) / 📷 사진 필수. 필수·선택 구분.
- 하루에 항목당 유효한 완료 1건. 한 명이 체크하면 Supabase Realtime으로 모든 직원 화면에 바로 반영.
- 사진은 비공개 저장소 `checklist-photos`(오늘 날짜 폴더에만 업로드 가능, 수정·삭제 불가). 올리기 전 1600px JPEG로 축소.
- 잘못 체크하면 "취소"(사유 필수). 기록은 "취소됨"으로 남음. 본인(당일) 또는 사장/관리자만 취소 가능.
- 관리자는 날짜별로 항목별 결과·한 사람·시각·취소 내역과 시간순 기록을 확인. 항목 추가/사용 중지는 사장만.
- 현재 업무 구성 (0009): 오픈 = 청소 상태 확인 / 마감 = 매출 정산(숫자: 포스 매출 마감 금액·현금 시재 금액) · 마감 청소 · 가스·전기 차단. 매출 정산 보고서의 총 매출 칸은 체크리스트의 포스 매출 금액으로 미리 채워짐.

## 매출 정산 보고서 (`/sales`, 월 매출 `/admin/sales`)

- 입력: 총 매출, 카드/현금/기타, 오늘 현금 지출·체크카드 지출, 메모.
- 결제수단 합계 ≠ 매출이면 입력 중 경고, 저장 시 한 번 더 확인.
- **마감 필수 체크리스트를 모두 완료해야 저장 가능** (DB가 확인).
- 하루 1건. 다시 작성하면 이전 보고서는 "무효"(사유 필수). 금액은 사장/관리자와 제출자만 조회.
- 월 매출(사장 전용): 일별 표 + 월 합계, 차이 있는 날·미제출 날 표시.

## NFC 태그 (유일한 출퇴근 방법)

관리 화면의 NFC 주소(`/nfc?t=매장코드`)를 NFC 태그(NTAG213 등)에 "URL"로 기록합니다. "NFC Tools" 같은 무료 앱으로 기록할 수 있습니다.
태그를 찍으면 출퇴근 화면이 열리고 버튼을 한 번 누르면 기록됩니다. 앱 첫 화면에는 출퇴근 버튼이 없습니다.
주소가 유출되면 [NFC 코드 새로 만들기] 후 태그를 다시 기록하세요. 태그를 못 찍은 직원은 사장/관리자가 "기록 추가"로 넣어 줍니다.

## 데이터베이스 (`supabase/migrations/`)

```
auth.users ─1:1─ profiles (이름, 이메일, role: owner|manager|staff, employment_type, is_active)
                    │ 1:N
                    ▼
                 attendance (work_date, clock_in, clock_out, edited_by, edited_at)
                    │ 1:N
                    ▼
                 attendance_logs (수정 이력)
store_settings (1행: NFC 코드) - 서버만 접근
```

출퇴근 기록은 서버 전용 함수 `clock_toggle_for()`로만 남습니다. 직원이 Supabase API를 직접 호출해 NFC 확인을 건너뛸 수 없습니다.
